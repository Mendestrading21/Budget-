# Budget iOS project

Use the project skill `/budget-v1` for substantial construction, audits, verification, and release work.

## Persistent rules

- Native SwiftUI + SwiftData + Swift Charts; iOS 17+.
- Financial amounts use Decimal, never Double.
- fr-CH formatting and Swiss financial terminology.
- Planned and actual money remain separate.
- Savings/investments are not living expenses.
- Internal transfers are neutral for household metrics and net worth.
- No external dependency, backend, bank-sync claim, or regulated advice in V1 without explicit approval.
- Preserve uncommitted work and never use destructive git commands.
- Build and test each completed vertical slice.
- Keep PROJECT_STATUS.md current.
- Use the visual references in `.claude/skills/budget-v1/references/visual/` for all UI work.
